# Labmark Feedback Desk

顶上一栏显示学生的姓名、学号以及第几次实验，往下分左右两大块，左边是作答摘录和同一实验结果的多张截图，右边是填写改分项的分数、应该使用哪个勾叉和显示已经写好的评语，然后有个按钮是确认写入 Word和导出 Excel。
